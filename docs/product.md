# Product

Boopy is the spatial interface for a person's existing personal AI.

**Your AI, in your world.**

Someone using a Quest selects a thing they can see, or a scene they saved. Their assistant
uses that selection, what it already knows, and outside reference material when the task
needs it. Boopy shows the reply as a few stable pieces of interface, next to the subject.
The person's answer or correction changes the task, and should go back to the same assistant.

A proposal stays a proposal until a person acts. If a result was not delivered, it was not sent.
If a reply cannot be delivered to the real assistant, say so. There is no live round trip unless
a send to the person's own assistant actually started. Do not present a local result as that
delivery.

Boopy is not a foundation model, a chat window in VR, a translation app, a scene labeler, a
required companion, a world generator, or an overlay on other applications.

"Any personal AI" is a later goal. Only name an assistant whose connection actually works.
Grok is the first one that works, one way: with the person's opt-in, each task goes to their
own Grok Bot as a moment, and the Bot's reply stays in its own chat. Muse is a possible later
one. A general model API, a second model with a copied prompt, or a database on the Mac is not
that person's assistant.

## The problem

Assistants are awkward when the work is about something physical. People describe the object,
read an answer somewhere else, then explain what they fixed. Seeing the object is not enough.
The missing piece is keeping the selection, the task, the action, and the continuing work
together.

A headset is worth using when pointing at the subject and answering there is easier than the
same assistant, the same image, and the same notes on a phone. A flat photo inside a headset
is not that proof by itself.

## A saved scene

A saved scene can illustrate the interaction. Korean text on a Morocco photo is sample data,
not the product. Saving a request with that scene does not create a lesson, a trip, or a
personal story.

A second task must use the same interaction. Consulting a manual while looking at a selected
object is the intended check. It does not need its own app.

## Limits

- Boopy runs as its own Quest app. Camera permission does not allow capturing another app's
  world or drawing on top of it.
- A saved photo has no depth and no later position in the room.
- Saving a photo does not invent what the person did, felt, or how well they speak.
- If a reply cannot be delivered to the real assistant, say so. Do not present a local result
  as that delivery.

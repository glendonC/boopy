# Interaction

This is the general task path. A task points at one source. The person's words are stored as
they said them. Opening a task does not create a lesson, a line of dialogue, or a story about
the person.

The assistant cannot set status, delivery, or continuity. Every task view says:

- continuity is local only
- delivery is not sent

There is no live round trip to the person's assistant.

## Actions

`voice_reply`, `wrong_subject`, `save_for_later`, `retry`, `cancel`.

A spoken answer is kept as a practice attempt. It is not written onto the source, and it is
not a confirmed story about the person.
